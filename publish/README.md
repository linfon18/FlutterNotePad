# FlutterNotePad 全平台发布版本

**版本**: 1.0.0  
**开发者**: linfon18 @ Loft Games  
**描述**: 仅 Flutter 初学入手尝试，不保证更新

## 可用版本

### ✅ Windows x64
- **文件**: `FlutterNotePad-Windows-x64.zip`
- **解压后运行**: `notepad.exe`
- **系统要求**: Windows 10/11 x64

### ✅ Web 版本
- **文件**: `FlutterNotePad-Web.zip`
- **使用方式**: 解压后部署到任意 Web 服务器，或直接用浏览器打开 `index.html`
- **兼容性**: 现代浏览器（Chrome, Firefox, Edge, Safari）

### ⏳ Android APK
- **状态**: 需要 Java 开发环境 (JDK)
- **构建命令**: `flutter build apk --release`

### ⏳ Android AppBundle
- **状态**: 需要 Java 开发环境 (JDK)
- **构建命令**: `flutter build appbundle --release`

### ⏳ Linux x64
- **状态**: 需要在 Linux 主机上构建
- **构建命令**: `flutter build linux --release`

### ⏳ macOS x64 / ARM64
- **状态**: 需要在 macOS 主机上构建
- **构建命令**: 
  - x64: `flutter build macos --release`
  - ARM64: `flutter build macos --release` (在 Apple Silicon Mac 上)

## 功能特性

- 📝 跨平台文本编辑器
- 🎨 支持自定义主题色和背景图片
- 🌓 深色/浅色/自动主题切换
- 📄 Markdown 预览和分屏编辑
- 🔍 文本查找功能（支持大小写敏感和全字匹配）
- 🪵 日志文件语法高亮（error/warn 着色）
- 📊 JSON 格式化、压缩、验证和 Dart 类生成
- 🔷 C# 语法高亮支持
- 🌐 多编码支持（UTF-8, GBK, Latin-1）
- 📦 大文件分段读取优化
